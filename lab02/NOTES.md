Рабочая папка - локальный проект на компьютере. Индекс - так называемая промежуточная зон, котору. я могу редактировать. Коммит - перекидывание из промежуточной зоны в облако, которое будет хранить все последующие версии проекта.
Git - локальная версия проекта на компьютере GitHub - облачное хранилище со всеми версиями проекта.
Использованные команды: git status - состояние папки и индекса. git diff - разница между рабочей директорией и индексом. git diff --staged - разница между индексом и последним коммитом.
